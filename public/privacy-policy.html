Meta Graph API v22.0 Compliant

Privacy Policy

Effective Date: September 25, 2026 | InstaDM Automation (AutoDM)

1. Instagram API Usage

InstaDM Automation utilizes official Instagram Graph API (v22.0) endpoints to provide comment-to-DM marketing automation for Instagram Business and Creator accounts. We adhere strictly to Meta Developer Platform Terms and API Rate Limits.

2. Comments and Messages

When users comment on your Instagram posts, our app processes incoming webhook payloads to match configured trigger keywords (e.g., "LOCATION"). In response, we dispatch automated Direct Messages with requested details and optional public comment replies.

3. Account Information

We access basic public account details: Instagram User ID, Username, Profile Picture URL, Account Type, Follower Count, and encrypted Meta OAuth Access Tokens.

4. Data Storage & Supabase

Account configurations and execution logs are stored securely using Supabase (PostgreSQL) infrastructure with Row Level Security (RLS). All data in transit is encrypted via TLS 1.3, and tokens at rest are encrypted using AES-256.

5. Data Retention

Webhook activity logs are stored for up to 30 days for analytics before automatic purge. Access tokens are deleted immediately upon account disconnection.

6. User Deletion Requests

Users can disconnect app access via Instagram settings (Settings & Privacy > Website Permissions > Apps and Websites) or submit a deletion request to privacy@instadm.app to request complete database erasure within 48 hours.

7. Contact Information

For questions or support, contact: privacy@instadm.app / support@instadm.app
